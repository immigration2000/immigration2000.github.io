그리드 인벤토리 시스템

그리드의 한 칸에서 시작해,
아이템과 장비의 상태를 연결합니다.

크기가 다른 아이템의 배치·이동과 장비 슬롯 간 전환을 다루는 Unreal Engine 인벤토리입니다. 데이터와 처리 로직을 UI에서 분리하고, 로컬 저장 API로 상태를 이어가는 구성을 개발하고 있습니다.

  • UE 5.8
  • C++
  • Blueprint / UMG
  • Data Table
  • Gameplay Tags
확인한 구현
그리드 이동·회전, 장착·해제 처리, 드래그 앤 드롭 경로, HTTP/JSON 스냅샷 저장 API
설계 포인트
Actor Component에 아이템 규칙을 두고 UI에서 호출. 저장 버전 충돌은 HTTP 409로 처리.
현재 범위
정적 소스·저장된 Blueprint 분석 기준. 이번 검토에서 UE 실행과 DB 왕복을 재현하지 않았으며, 서버는 로컬 학습용입니다.
구현과 다음 단계를 자세히 보기

C++의 이동·장비 처리 함수와 UMG에 저장된 호출 노드를 정적으로 확인했습니다. 실제 호출 대상의 컴파일러/UHT 검증과 실행 검증은 별도입니다. ASP.NET Core·EF Core·MSSQL 코드에는 로그인, 인벤토리 조회·저장, 버전 충돌 처리가 있습니다.

운영용 게임 서버, 전체 아이템 규칙의 서버 검증, 멀티플레이 Replication은 완료 항목으로 주장하지 않습니다. 브라우저 데모는 이 페이지에서 별도로 만든 배치 개념 예제입니다.

비공개 저장소의 코드와 원본 에셋은 이 사이트에 포함하지 않았습니다. 공개 가능한 시연 자료를 정리하는 것이 다음 단계입니다.
